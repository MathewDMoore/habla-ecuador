# Habla translation of regional recording transcripts — build 119

Practice → Native voices · regional speaking pilot → choose a recording → Spanish transcript & Habla translation. The complete published Spanish transcript is available without running speech recognition again. Choose U.S. or U.K. English and tap Translate with Habla. The initial English choice comes from the app preference; explicit pilot choices stay selected across recordings for this page session without altering the main translator's language pair.

The English draft is editable. Drafts and edits are kept in page memory separately for each recording, English choice and on-device/online route. Closing or reloading the page discards these session drafts. The main source editor, document state, translation history, saved glosses and conversation state are not replaced or used as the transcript source.

The control calls the existing `requestGeneralTranslation` pipeline with explicit Spanish locale, English target, everyday purpose, complete transcript text, on-device route and stale-result guard. It retains existing chunk limits, quota/timeout errors and English-variety conversion. No extra translation provider or microphone/audio-upload path is introduced. The existing on-device setting is honored; missing/failed packs do not silently go online. Online mode sends only the public transcript text to the existing MyMemory provider after the explicit tap. No translation request is made by loading the page or opening the transcript.

Stop translation, changing recording/English choice/mode, closing the pilot or transcript, navigation and document hiding invalidate the request. Already-sent shared provider requests may finish, but stale results cannot replace the displayed text and no further segments are requested by that canceled operation. Typing into a draft also cancels its pending replacement. Errors preserve the Spanish text and previous English draft. Provider output is assigned to a textarea value, never rendered as HTML.

## Caption boundary

These are complete untimed transcripts, not synchronized captions. They do not replace the iPhone player's generated-English subtitle menu or change the MP4's audio-language metadata. Both languages can be read with the inline video; native fullscreen displays its own player controls. Timed bilingual captions need checked segment alignment before a later release. No timestamps, subtitle tracks, phoneme scores or acoustic-pronunciation results are invented.
