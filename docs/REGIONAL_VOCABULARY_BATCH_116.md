The regional index had 49 entries, English views indexed the U.S./U.K. glosses, and all six Spanish country selectors were supported. ## Behavior and safeguards

- New data lives in regional-vocabulary.js and is included before spanish-context.js on both hosted pages and in the offline shell. No asynchronous data fetch or new provider is added.
- New entries use explicit usage types rather than guessing from spelling. Country-specific meanings of llucho, bacán, atatay, vaina, arrecho, chimbo and palta are separated. Vaina retains a Venezuelan vulgar mark distinct from the selected informal-country sense. Chingón praise entries explain source label differences and use a conservative coarse-language warning rather than treating all senses identically.
- Regional cards render each new original example with U.S./U.K. meaning and the existing device speech/practice controls. Existing phrase/story/document/music workflows and compact dropdowns remain.
- Negative/contrast notes in this batch are not indexed as English counterpart evidence: naked cannot match the Bolivian hat only because its warning mentions Ecuadorian naked usage. Actual headwords, glosses, positive scope and country labels remain searchable. Existing search semantics for older entries are unchanged.
- No new automatic translation, slang-detection or profanity-substitution rule is added. A new dictionary headword cannot silently become a universal translation. Existing exact-match, ambiguity, full-phrase, negative-case, editable-translation and saved-gloss regressions remain required.
- No private papers, private recordings, lyrics, MP3 partials, generated cache files or signing changes are included. Native 0.1.16 recording-import PR remains separate.
