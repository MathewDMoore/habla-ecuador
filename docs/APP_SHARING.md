# Share Habla — Home Screen setup guide (build 197)

Every generated Share app / Copy link invitation includes `tour=home-screen`, along with the existing allowlisted language and regional routing parameters. Recipients see a two-step, English/Spanish guide with the shared icon artwork and a clearly labeled widget preview. Closing the guide restores the original destination, including regional dictionary invites. This focused guide does not mark the main onboarding tutorial as completed.

The guide explains Safari Add to Home Screen (including links opened inside WhatsApp), Android browser installation, and native iPhone widget setup. It explicitly explains that the website icon does not install WidgetKit and that no public native app installation link exists yet. A Home Screen guide button in the sharing panel reopens the guide on either web entry point. Open Graph artwork is available for sharing services that use link previews; those services control whether they display it.

Private text, recordings, documents and local history are never included in the shared URL. There is no automatic native installation or automatic Home Screen modification. This hosted update does not require rebuilding the installed iPhone companion.
