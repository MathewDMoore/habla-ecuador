# Short lessons inspired by supplied teaching examples

Build 135 adds **Practice → Short lessons · one useful idea**, before the existing regional/English speaking lessons. The same learning goal selects Ecuadorian Spanish, U.S. English or U.K. English. UI language remains independent.

The user's recordings show a short ya/todavía introduction (21:54), a por/para comparison (21:58), and a future-tense explanation (22:20). We borrow a compact explanation → contrasting examples → usable situation format. This is original text and device speech; the app does not bundle the creators' footage, voices, likenesses or promotional material. The first recording is only about 21 seconds and does not contain a complete explanation of both words.

Spanish topics: ya/todavía/todavía no; recipient, purpose, destination, cause and route examples for por/para; voy a + infinitive and future endings. English topics: already/still/not yet; for a recipient and to + verb for purpose; going to and will in context. These are examples and starting points, not universal rules. Spanish future endings remain explicitly included.

Each topic has three situations. The model is visible by default. “Try without reading” hides examples and model; “Show me the phrase” restores them. Moving to another situation preserves that optional recall choice. Revealing the model enables the existing stable-prompt speaking practice. Different valid responses are acknowledged; recognition feedback compares words with the displayed model and does not score communicative understanding.

Goal, topic, situation, recall and navigation changes cancel the current practice. Navigation/closing stops speech. An open visible short lesson protects automatic-update reloads. Text and module are included in the offline shell; speech availability follows the existing device model.

Validation: existing 32 unit suites plus real-page browser coverage for both app shells, 320/390px, all three learning goals, all topics and situations, audio locale, optional reveal, stable microphone prompt, Spanish UI, explicit goal persistence, and navigation protection. The standalone translator intentionally hides navigation; its lesson DOM is opened programmatically for compatibility coverage. Speech and recognition boundaries are simulated; physical iPhone voice/recognition behavior requires device verification.
