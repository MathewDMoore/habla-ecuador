# Dictionary speaking practice — build 110

Hosted v0.26.0/build 110 adds a collapsed Speaking practice section beside the existing audio on regional dictionary, cultural expression and evidence/learner cards. It reuses each card's Spanish audio text and locale, with separate choices for slash-separated forms and available Spanish examples. Known terminal grammatical labels such as “(noun)” are excluded from practice prompts. Dictionary entries, sources, register/context/uncertainty metadata and translation safeguards are unchanged.

The learning loop is hear the model, read the visible prompt, speak, inspect recognition feedback, then retry a focused part. As partial recognition arrives, ordered word alignment marks recognized/unmatched target words and labels them unconfirmed. Confirmed results compare complete word sequences; extra words, different order and repeated-word omissions cannot earn a full match. Text matching ignores punctuation and written acute accents but preserves the n/ñ distinction. This checks recognized words; it does not evaluate spoken stress, phonemes, accent, fluency or acoustic quality.

For a confirmed mismatch, Hear this part and Practice this part use the first unmatched target word plus up to two following words. If only extra words were recognized, the full target is used. This is a recognition-based retry focus, not a diagnosis of a pronunciation error. Focus practice retains the original full prompt above the selected part; the original word/example choices remain available. No coaching is inferred from provisional-only results.

Model playback cancels an active practice mic before it can transcribe the model. Only one practice session owns the microphone. Closing the section, replacing the filtered card, changing prompts, switching views, backgrounding or starting another practice releases it. Tap Start/Stop is explicit, startup/listening/finishing/errors are visible, captures stop at 20 seconds and a three-second end timeout releases a stuck provider. Missing recognition support disables the microphone with an explanation while model playback remains available. Long evidence headings wrap at narrow mobile widths so the page and bottom navigation stay within the viewport.

The feature uses the existing speech provider/native bridge. Offline recognition and available voices depend on device support and installed resources; it does not add an assessment service, account, paid dependency, audio upload endpoint, recording file or persistent practice log. Browser recognition may use its existing provider's online service. Native code, signing and experimental recognition branches remain unchanged; no Xcode rebuild is required for this hosted update.

Design references: Duolingo describes listen/speak exercises and immediate feedback at https://blog.duolingo.com/covering-all-the-bases-duolingos-approach-to-speaking-skills/ . Speechace documents separate word/syllable/phoneme assessment at https://api-docs.speechace.com/ . These informed the interaction and the distinction between word recognition and acoustic assessment; neither service is integrated or copied.
